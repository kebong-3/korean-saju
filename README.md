# korean-saju · 한국 사주명리 엔진

외부 의존성 **0개**인 Python 사주명리 엔진 + CLI + MCP 서버 + Claude 플러그인.

절기표나 음력표를 내장하지 않습니다. **VSOP87 태양 황경**과 **Meeus 합삭 알고리즘**으로 절입 시각과 한국 음력을 직접 계산해서, 1900~2100년 어느 날짜든 한국천문연구원 발표값과 분 단위로 일치합니다.

```text
$ ksaju 1990-05-15 14:30 -g 여

|  | 시주 | 일주 | 월주 | 연주 |
|---|---|---|---|---|
| 천간 십성 | 상관 | 일간(나) | 겁재 | 비견 |
| 천간 | 癸 계·수 | 庚 경·금 | 辛 신·금 | 庚 경·금 |
| 지지 | 未 미 | 辰 진 | 巳 사 | 午 오 |
| 지지 십성 | 정인 | 편인 | 편관 | 정관 |
| 지장간 | 丁 乙 己 | 乙 癸 戊 | 戊 庚 丙 | 丙 己 丁 |
| 12운성 | 관대 | 양 | 장생 | 목욕 |
...
- 강약: 중화(54.7%) · 득령 X 득지 O 득세 O
- 격국: 편관격(칠살격)
- 용신: 토 / 희신 화 / 기신 목 · 조후용신 수
```

## 기능

| 영역 | 내용 |
|---|---|
| **만세력** | 절입 시각 기준 연·월주(입춘 기준 연 변경), 일주, 오서둔 시주 |
| **시간 보정** | 경도별 지방평균시(서울 −32분), 균시차(진태양시), **한국 표준시 이력**(1954~61 UTC+8:30 등), **과거 서머타임**(1948~51, 1955~60, 1987~88) 자동 보정 |
| **자시 처리** | 정자시(23시 일주 변경) / 야자시·조자시 선택 |
| **음력** | 천문 계산 기반 한국 음력 양↔음 변환, 윤달(2033년 윤11월 같은 경우 포함) |
| **원국 분석** | 지장간(여기·중기·정기), 십성, 12운성, 오행 개수·가중 비중 |
| **강약** | 월령 가중 점수, 득령·득지·득세, 5단계(극신강~극신약) |
| **격국** | 자평진전식: 건록·양인 우선, 월지 지장간 투출, 종격·괴강격 가능성 표시 |
| **용신** | 억부(살인상생·군겁쟁재 등 상황별 근거) + 궁통보감식 조후, 희·기·구·한신 |
| **관계** | 천간합·충, 육합, 삼합·반합, 방합, 충, 형(삼형·상형·자형), 파, 해, 원진, 귀문 |
| **신살** | 천을귀인, 문창, 천덕·월덕, 양인, 괴강, 백호, 홍염, 금여, 도화·역마·화개, 공망, **12신살**(연지·일지 기준) |
| **운** | 대운(3일=1년 정밀 계산, 순역행), 세운 10년(원국과의 작용), 월운(절입 시각), 일진 |
| **궁합** | 일간 생극합, 일지(배우자궁)·띠·월지 합충, 서로의 용신·부족 오행 보완 점수 |
| **출력** | Markdown 표 / JSON / LLM용 compact |
| **경계 경고** | 절입 2시간 이내·시 경계 10분 이내 출생은 경고 표시 |

## 설치와 사용

```bash
pip install .            # 또는 PYTHONPATH=src 로 바로 실행
ksaju 1990-05-15 14:30 -g 여                 # 양력
ksaju 1990-04-21 14:30 --lunar -g 여         # 음력 (윤달은 --leap)
ksaju 1990-05-15 -g 남 --format json         # 시각 미상 → 삼주
ksaju 1975-08-20 06:10 --lon 129.08          # 부산 출생 경도 보정
ksaju 2000-01-01 23:40 --zi split            # 야자시 학파
ksaju compat 1990-05-15/14:30/여 1988-11-03/08:00/남
ksaju lunar 2025-08-15                       # 음력→양력
ksaju solar 2025-10-06                       # 양력→음력
ksaju day 2026-01-01                         # 일진
```

```python
from ksaju import read_saju, read_compatibility
r = read_saju(1990, 5, 15, 14, 30, gender="여", longitude=126.98)
r.to_markdown(); r.to_dict(); r.to_compact()
r.analysis.yongshin, r.daewoon, r.seun
```

## Claude 플러그인 / MCP

이 저장소는 그대로 Claude Code 플러그인입니다(`.claude-plugin/`, `.mcp.json`, `skills/saju-reading`).
MCP 서버는 Python 표준 라이브러리만 씁니다. Node.js나 pip 설치가 필요 없습니다.

```json
{ "mcpServers": { "korean-saju": { "command": "python", "args": ["/path/to/korean-saju/scripts/mcp.py"] } } }
```

도구: `calculate_saju`, `saju_compatibility`, `lunar_to_solar`, `solar_to_lunar`, `day_ganzi`
