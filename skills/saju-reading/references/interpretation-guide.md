# 사주 해석 기준표

## 천간 물상
- 甲 큰 나무: 곧음·추진력·리더십 / 乙 화초·덩굴: 유연·적응·실속
- 丙 태양: 밝음·공개성·열정 / 丁 촛불: 섬세·집중·헌신
- 戊 큰 산: 묵직·포용·신용 / 己 논밭: 실용·관리·돌봄
- 庚 바위·원석: 결단·의리·강직 / 辛 보석: 예리·완벽주의·미감
- 壬 바다: 지혜·스케일·유동성 / 癸 빗물: 직관·감수성·침투력

## 십성
- 비견: 자립·동료·경쟁 / 겁재: 승부욕·확장·재물 분산
- 식신: 재능·표현·여유·생산 / 상관: 언변·창의·기존 질서 비판
- 편재: 큰 돈·사업 감각·활동성 / 정재: 성실한 수입·관리·안정
- 편관: 압박 속 성취·카리스마 / 정관: 명예·규칙·직장 안정
- 편인: 독특한 학문·직관·기술 / 정인: 학업·자격·문서·후원

### 십성 조합(자주 쓰는 구조)
- 식신생재: 재능이 돈이 됨 — 전문직·프리랜서·사업
- 상관견관: 윗사람·조직과 마찰 — 독립·창작 쪽이 유리
- 살인상생: 압박을 배움·자격으로 전환 — 고시·연구·관리직
- 재극인: 현실이 공부를 누름 — 실무형
- 군겁쟁재: 비겁이 많아 재물을 나눔 — 동업·보증 주의
- 관인상생: 조직에서 인정받고 승진

## 궁위
연주=조상·유년(1~15) / 월주=부모·형제·사회(15~30) / 일주=나·배우자(30~45) / 시주=자녀·말년(45~)

## 12운성(봉법)
장생·관대·건록·제왕 = 상승 / 쇠·병·사·묘 = 내실·정리 / 절·태·양·목욕 = 전환·준비·변동

## 합충형파해
- 합: 결합·협력(합화하면 그 오행 강화, 합거되면 원래 작용 약화)
- 충: 변동·이동·충돌 — 월지충은 직장·환경, 일지충은 배우자·거처 변화
- 형: 마찰·조정·수술/소송 상징 / 파: 어긋남 / 해: 서운함 / 원진: 애증 / 귀문: 예민·영감

## 강약과 용신
- 신강 → 식상(설기)·재성·관성 중 유리한 것 / 신약 → 인성·비겁
- 조후(궁통보감): 巳午未월은 수, 亥子丑월은 화가 필요
- 통관: 두 세력이 싸울 때 중간 오행(예: 금목상전 → 수)
- 종격: 극신강·극신약에서 강한 세력을 따르는 특수격 — 엔진은 가능성만 표시하므로 신중히
- 엔진 용신은 억부 기본값이다. 계절·조후·격국을 함께 보고 설명한다.

## 운 해석 요령
- 대운 천간은 앞 5년, 지지는 뒤 5년에 더 강하다는 통설(유파별 차이)
- 용신·희신 운: 확장·도전에 유리 / 기신·구신 운: 내실·건강 관리·무리한 확장 자제
- 세운이 원국 일지를 충하면 이사·관계 변화, 월지를 충하면 직장·환경 변화로 자주 읽는다

## 오행별 생활 조언
- 목: 초록, 동쪽, 기획·교육 / 화: 빨강, 남쪽, 발표·홍보 / 토: 노랑, 중앙, 조정·관리
- 금: 흰색, 서쪽, 분석·정리 / 수: 검정·남색, 북쪽, 연구·휴식
