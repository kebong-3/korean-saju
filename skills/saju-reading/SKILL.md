# 한국 사주 풀이

korean-saju MCP 도구로 계산한 결과만 근거로 풀이한다. 간지·십성·대운을 직접 추측하거나 암산하지 않는다.
MCP 도구를 쓸 수 없으면 `python scripts/mcp.py` 대신 CLI로 계산한다:
`python -m ksaju 1990-05-15 14:30 -g 여 --format compact` (PYTHONPATH=src).

## 1. 정보 수집

- 필요: 생년월일, 양력/음력(음력이면 윤달 여부), 출생 시각, 성별, 가능하면 출생 지역(경도 보정).
- 시각을 모르면 그대로 진행한다. 엔진이 삼주(연·월·일)로 계산하므로 시주 관련 판단(자녀운·말년운)은 생략하거나 참고용임을 밝힌다.
- 결과에 `주의`(절입·시 경계 출생)가 있으면 반드시 사용자에게 알리고 앞뒤 경우를 함께 언급한다.
- 이미 대화에 정보가 있으면 다시 묻지 않는다.

## 2. 계산

| 질문 | 도구 |
|---|---|
| 사주 전체 | `calculate_saju` (기본 compact, 표를 원하면 `format: "markdown"`) |
| 궁합 | `saju_compatibility` |
| 음양력 변환 | `lunar_to_solar` / `solar_to_lunar` |
| 오늘·특정일 일진, 택일 | `day_ganzi` (birth를 함께 주면 그 사람 기준 십성·합충) |
| 특정 연도 기준 운 | `calculate_saju`의 `today`를 그 해 날짜로 |

## 3. 풀이 순서

1. **원국 요약** — 일간의 성정(물상), 월령과 강약(득령·득지·득세), 격국.
2. **오행 균형** — 비중(%) 기준 과다·결핍 오행과 의미, 용신이 왜 필요한지(억부/조후 근거).
3. **십성 구조** — 비겁·식상·재성·관성·인성 비중으로 성향·직업·재물·관계 패턴. 남녀별 육친(남: 재성=배우자, 관성=자녀 / 여: 관성=배우자, 식상=자녀).
4. **궁위** — 연주(조상·유년), 월주(부모·사회·청년), 일주(나·배우자), 시주(자녀·말년).
5. **합충형파해·신살** — 결과에 나온 것만 다루고 신살은 보조 근거로만 쓴다.
6. **대운** — 현재 대운(★)의 천간·지지 십성과 12운성으로 10년 흐름, 다음 전환 시점.
7. **세운·월운** — 올해/특정 해 간지가 원국과 만드는 작용(결과의 `작용` 목록)을 대운과 함께 본다.
8. **실천 조언(개운법)** — 용신 오행의 색·방위·활동·직무를 가볍게 제안.

세부 해석 기준은 `references/interpretation-guide.md`를 필요할 때 읽는다.

## 4. 궁합

엔진 점수는 참고값이다. 일간 생극·합, 일지(배우자궁) 합충, 서로의 용신을 상대가 채워주는지를 중심으로 잘 맞는 점과 조율할 점을 함께 제시한다.

## 5. 태도

- 단정적 예언·공포 조장 금지. "~한 경향", "~에 유리한 시기"처럼 쓴다. "반드시 맞힌다"는 식의 표현을 쓰지 않는다.
- 건강·법률·투자·진로의 중대한 결정은 사주로 판단하지 말고 전문가 상담을 권한다.
- 명리 용어는 처음 나올 때 짧게 풀어준다(예: 식신 = 내가 생하는 같은 음양, 표현·재능).
- 유파에 따라 다른 지점(용신 선정 억부 vs 조후, 신살 비중, 야자시 처리, 경도 보정 여부)은 그렇다고 밝힌다.
