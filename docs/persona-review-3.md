## 20명에게서 나온 개선점 (우선순위)

### P0 — 여러 명이 걸리거나 신뢰·법적 위험
1. **앱 안 '내 기록 모두 지우기' + 앱 안 의견 보내기** (7·19): 개인정보 삭제권을 화면에서 바로. 의견은 공개 게시판이 아니라 비공개로 받기.
2. **알림 시간 선택** (3·4·10): 무료 요금제의 예약 작업 2개를 '아침 7시'와 '저녁 9시'로 나누고, 일요일 돌아보기는 저녁 알림에 합친다.
3. **아이에 대한 표현 다듬기** (9·18): 자녀 별명·설명에서 '단련시키는', '호랑이' 같은 말을 아이 쪽에선 부드럽게. 출산 택일은 정중히 거절하는 안내 문구.
4. **색약·스크린리더** (13·14): 케미 선에 숫자나 점선 같은 모양 구분을 넣고, 별자리 그림에 대체 글(누구와 누구 케미 몇)과 이름 없는 버튼 7개에 이름 붙이기.

### P1 — 많이 쓰는 사람을 붙잡는 것
5. **택일·우리 둘 좋은 날 목적 확장** (5·6·16): 결혼식, 개업·이전.
6. **하루 경계 설정** (4): 구슬·오늘 기준을 '자정' 또는 '새벽 5시'로 고르기(교대근무).
