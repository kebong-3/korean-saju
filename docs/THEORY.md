# 계산 규칙과 이론적 근거

## 1. 시간
1. 입력한 벽시계 시각을 그 시대 한국 표준시와 서머타임으로 UTC로 바꿉니다.
   - 1908-04 ~ 1911: UTC+8:30 / 1912 ~ 1954-03-20: UTC+9 / 1954-03-21 ~ 1961-08-09: UTC+8:30 / 이후 UTC+9
   - 서머타임: 1948~1951, 1955~1960, 1987~1988 (날짜는 관보 기준 근사값)
2. **연·월주**는 실제 순간(UTC)의 태양 황경으로 정합니다. 315°(입춘)가 寅월이고 연도도 입춘에 바뀝니다.
3. **일·시주**는 지방시로 정합니다. 기본값은 경도 보정(UTC + 경도×4분)이고 `true_solar`를 켜면 균시차도 더합니다.
   - 경도 보정을 하지 않는 학파도 있어서 `apply_lmt=False` / `--no-lmt` 옵션을 둡니다.
4. **자시**: `unified`(기본값)는 23시에 일주가 바뀝니다. `split`은 야자시로, 23~24시는 당일 일주에 다음날 자시를 씁니다.

## 2. 천문
- 태양 황경: VSOP87 지구 L0~L5·R0~R2 축약 급수, FK5 보정, 장동 4항, 광행차
- 합삭: Meeus 49장 주기항 25개와 행성 섭동 14항
- ΔT: Espenak & Meeus 다항식

## 3. 한국 음력
- 합삭이 있는 날(한국 표준시 기준)이 초하루입니다.
- 동지가 들어 있는 달이 11월입니다. 동지에서 다음 동지까지 13개월이면 중기가 없는 첫 달이 윤달입니다.
- 이 규칙은 한국천문연구원 방식과 같습니다. 중국 음력과는 동경 120°/135° 차이 때문에 드물게 하루가 다를 수 있습니다.

## 4. 분석 규칙
| 항목 | 규칙 | 근거 |
|---|---|---|
| 지장간 | 여기·중기·정기 일수(예: 寅 = 戊7 丙7 甲16) | 연해자평, 월률분야 통설 |
| 강약 | 천간 1, 연·시지 1, 일지 1.5, 월지 3 가중. 지지는 지장간 일수 비율로 나눔 → 비겁+인성 비중 | 월령 중시(자평진전), 득령·득지·득세 |
| 격국 | 월지가 록이면 건록격, 양간 제왕이면 양인격. 그 밖에는 월지 지장간 중 천간에 투출한 것(정기→중기→여기, 비겁 제외), 없으면 정기 | 자평진전 |
| 용신(억부) | 신강하고 인성이 많으면 재성, 비겁이 많으면 관성 또는 식상. 신약하고 재성이 많으면 비겁, 관성·식상이 많으면 인성 | 적천수, 명리정종 |
| 조후 | 巳午未월에 수가 15% 미만이면 수, 亥子丑월에 화가 15% 미만이면 화 | 궁통보감 |
| 신살 | 일간·연간 기준 귀인류, 월지 기준 천덕·월덕, 삼합 기준 12신살 | 삼명통회 |
| 대운 | 양년생 남자·음년생 여자는 순행, 나머지는 역행. 출생부터 다음(이전) 절까지 일수 ÷ 3 = 대운수 | 연해자평 |

## 5. 한계
- 궁통보감의 일간×월령 120개 조후표 전체를 쓰지 않고 계절 규칙으로 단순화했습니다.
- 종격·화격은 판정하지 않고 가능성만 알려줍니다.
- 지장간 일수와 신살 표는 학파마다 조금씩 다릅니다(예: 申의 여기를 戊로 볼지 己로 볼지).
