## 공통으로 나온 문제 → 고칠 것 (우선순위)

### P0 — 신뢰와 이탈에 바로 영향
1. **사용설명서가 템플릿처럼 보인다** (3·5·6번)
   네 칸에 사람마다 다른 근거를 섞는다: 일지 충·합(“둘 다 ○○라 서로 부딪히는 자리”), 용신 채움 정도, 정·편(정인 vs 편인), 실제 관계. 같은 유형이어도 문장이 겹치지 않게 변형을 3배 이상으로.
2. **홈이 길고 기능이 많다** (1·8번)
   홈 첫 화면 = 오늘 점수 + 오늘 한 가지 + 오늘의 인연(또는 패) 세 개만. 나머지는 '더 보기'로. 이름 같은 '도감' 둘 중 하나는 '옷장'으로.
3. **근거가 안 보인다** (5·6번)
   점수·용신·관계 옆에 "왜?" 한 줄(예: “오늘 일진 乙巳가 내 일지와 합 +8, 용신 화가 들어와 +6”). 용신은 '억부로는 화, 조후로는 수' 둘 다 보여 주고 고를 수 있게.
4. **글씨·버튼이 작다** (8·9번)
   설정에 '글자 크게'(본문 17px, 버튼 48px). 손글씨 글꼴은 장식에만. 홈의 36px 미만 터치 영역 27개 정리.

### P1 — 넓은 사용자층
5. **말투·색 선택** (6·8번): '차분한 냥이'(다냥 줄이기)와 '차분한 색' 테마. 20대 여성 톤은 기본값으로 유지.
6. **힘든 날·지난 시기 문장 점검** (7·10번): '정비' 날은 “이렇게 쓰면 좋은 날”로, 과거 대운은 “버텨 낸 시기”로. 점수 숨기기 옵션.
7. **직장 관계 개인정보** (3·8번): 직장 사람을 올릴 때 “본인에게 동의받았나요?” 안내. 관계 꼬리표를 서버 대신 내 폰에만 저장하는 선택지. 저장되는 것 목록을 지도 화면에 바로 보여 주기.
8. **공유 품질** (2번): 스토리 카드에 앱 글꼴을 넣어 같은 모양으로(글꼴 일부만 잘라 이미지 안에 포함). 카카오 공유 버튼(앱 키 필요). 링크 미리보기 실제 확인.
9. **알림 시간 선택** (9번): 7시 / 8시 / 12시 / 21시.

### P2 — 새 기능
10. **목표일 모드** (7번): 시험·면접·이사 날짜를 넣으면 그날까지 컨디션 흐름과 준비 체크.
11. **가족 지도** (9번): 배우자·아이·부모를 한 화면에.
12. **구슬 보너스** (2번): 냥이와의 약속을 지키면 다음 날 +1알(사는 게 아니라 버는 구조, 재방문과 맞물림).
13. **전문가 보기** (5번): 지장간·대운수 계산 근거·학파 선택을 한 탭에.

> 한 번에 다 하기보다 **P0의 1(설명서 개인화)과 2(홈 정리)** 를 먼저 하길 권한다. 가장 많은 후기가 걸려 있고, 공유·재방문 둘 다에 직접 영향이 있다.
